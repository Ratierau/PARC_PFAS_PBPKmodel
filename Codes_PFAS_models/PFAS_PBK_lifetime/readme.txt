For running the model, put all files in the same folder and set that folder as WD.
Open the file scenario_iv_pfoa.R or scenario_iv_pfos.R.
Install all required libraries.
Run the code (function pbk.model() will be loaded from pfas_pbk_lifetime_model.R, wrapper function faster.convergence.full.param() from faster_convergence_full_param.R.
The results are saved as an .xlsx file within the same directory.
